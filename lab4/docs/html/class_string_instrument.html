Detailed Description

Промежуточный класс струнных музыкальных инструментов.

Хранит общие параметры струнных инструментов: количество струн, натяжение и значения натяжения отдельных струн. Класс сам по себе не задаёт способ извлечения звука — это делают конкретные наследники.
