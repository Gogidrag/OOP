Detailed Description

Абстрактный базовый класс для всех музыкальных инструментов.

Класс хранит общее для инструментов название и предоставляет интерфейс для воспроизведения звука, настройки и определения типа. Также он ведёт общую статистику: количество созданных объектов и количество вызовов метода play() для каждого типа инструмента.

От этого класса наследуются промежуточные классы струнных и духовых инструментов, а от них — конкретные инструменты.
