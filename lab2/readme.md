## ЭТАП 1: Определение сущности

### 1. Что представляет собой объект?

Электронный кошелёк — объект, который хранит информацию о владельце,
валюте, текущем балансе и состоянии кошелька (активен/заблокирован),
а также позволяет выполнять финансовые операции: пополнение, списание,
перевод между кошельками, блокировку и разблокировку.

### 2. Какие данные характеризуют объект?

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `int` | Уникальный идентификатор кошелька |
| `owner` | `Owner` (пользовательский тип) | Владелец (ФИО + паспорт) |
| `balance` | `double` | Текущий баланс |
| `currency` | `Currency` (пользовательский тип) | Валюта (RUB/USD/EUR) |
| `isBlocked` | `bool` | Заблокирован ли |
| `objectCount` | `static int` | Счётчик существующих объектов |

### 3. Какие действия можно выполнять?

| Действие | Метод |
|----------|-------|
| Пополнить | `deposit(amount)` |
| Списать | `withdraw(amount)` |
| Перевести | `transfer(other, amount)` |
| Заблокировать | `block()` |
| Разблокировать | `unblock()` |
| Показать информацию | `printInfo()` |
| Проверить корректность | `isValid()` |

### 4. Какие состояния недопустимы?

1. Баланс не может быть отрицательным: `balance >= 0`
2. ID должен быть положительным: `id > 0`
3. Имя владельца не может быть пустым: `!owner.fullName.empty()`
4. Паспорт не может быть пустым: `!owner.passport.empty()`
5. Заблокированный кошелёк не выполняет финансовые операции
