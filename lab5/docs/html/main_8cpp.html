Подробное описание

Лабораторная работа №5. Геометрические примитивы (вариант 7).

Программа читает 10 фигур из файла, считает площадь и центроид, проверяет выпуклость четырехугольников и перемещает фигуры. Стандарт языка — C++14.

Заметки
Вершины задаются по порядку вдоль границы без самопересечений.

Функции

◆ calculateCentroid()

template<typename T, size_t V>
Point< long double > calculateCentroid ( const Polygon< T, V > & p)

Вычисляет центроид — центр площади фигуры.

Суммирует произведения соседних вершин по формуле Гаусса. Каждую сумму для координат центра делит на утроенную знаковую сумму. Даже при целых координатах вершин центр может быть дробным.

Параметры шаблона
TТип координат.
VКоличество вершин.
Аргументы
pИсходный многоугольник.
Возвращает
Координаты центра типа long double.
Исключения
domain_errorЕсли знаковая площадь равна нулю.

◆ main()

int main ( )

Главная функция программы.

Открывает polygons.txt, считывает ровно 10 фигур и выбирает шаблон по числу вершин: 3 — int, 4 и 5 — double. В конце выводит счетчики объектов.

0 при успешной работе, 1 при ошибке.

Перемещает многоугольник по плоскости.

Предоставляет функции translate доступ к закрытым вершинам.

Прибавляет dx к X и dy к Y каждой вершины. Доступ к массиву vertices открыт через friend. Форма и площадь при переносе сохраняются.
