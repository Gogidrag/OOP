Подробное описание

Полная специализация класса для четырех вершин типа double.

Площадь вычисляется без цикла, поскольку число вершин известно заранее. Дополнительно можно проверить строгую выпуклость.

◆ isConvex()

bool Polygon< double, 4 >::isConvex ( ) const
inline

Проверяет, является ли четырехугольник строго выпуклым.

Для каждой тройки соседних вершин вычисляет векторное произведение сторон. Если все повороты одного ненулевого знака, фигура строго выпуклая.

Возвращает
true — строго выпуклый; false — разные знаки или нулевой поворот.
