Подробное описание

template<typename T, size_t V>
class Polygon< T, V >

Шаблонный класс многоугольника с фиксированным числом вершин.

Хранит вершины в массиве, считает площадь и число созданных объектов. static_assert запрещает неподходящие типы и число вершин меньше трех.

Параметры шаблона
TЧисловой тип координат (кроме bool).
VКоличество вершин; задается при компиляции.

friend

Предоставляет функции translate доступ к закрытым вершинам.

Прибавляет dx к X и dy к Y каждой вершины. Доступ к массиву vertices открыт через friend. Форма и площадь при переносе сохраняются.
